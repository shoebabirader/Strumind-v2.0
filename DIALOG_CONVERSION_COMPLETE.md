## What Was Changed

### From Modern Design:
- shadcn/ui Dialog components
- Rounded corners and shadows
- Modern color schemes
- Badge components
- Lucide icons in titles
- Select dropdowns with complex styling

### To Classic Professional Design:
- ClassicDialog components
- Sharp corners and subtle borders
- Professional gray/blue color palette
- Clean, minimal styling
- Form-based layouts
- Standard HTML select elements
- CSS variable-based theming

## Design System Features

### ClassicDialog Components:
- `ClassicDialog` - Main dialog wrapper
- `ClassicDialogContent` - Content container
- `ClassicDialogHeader` - Header section
- `ClassicDialogTitle` - Title text
- `ClassicDialogBody` - Main content area
- `ClassicDialogFooter` - Action buttons area

### Form Elements:
- `.form-group` - Form field container
- `.form-label` - Field labels
- `.form-input` - Input fields, selects, textareas

### Color Scheme:
- `--bg-primary` - Main background
- `--bg-secondary` - Secondary background
- `--text-primary` - Primary text
- `--text-secondary` - Secondary text
- `--border-color` - Border color
- `--accent-blue` - Primary action color
- `--status-error` - Error/destructive actions
